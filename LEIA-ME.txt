HiChord para Android (app nativo) - como gerar o APK sem instalar nada

1. Crie uma conta e um repositorio novo no github.com (pode ser privado).
2. Envie TODO o conteudo desta pasta para o repositorio (inclusive a pasta oculta .github).
   Pelo site: Add file > Upload files, arrastando as pastas.
3. Abra a aba Actions > "Build APK" > Run workflow. Espere uns 5 a 10 minutos.
4. Quando terminar, abra a execucao e baixe "HiChord-apk" (zip com app-debug.apk).
5. Instale no celular (permita "instalar apps desconhecidos").

Controle: A B X Y L1 R1 R2 = acordes | analogico esquerdo = 7a, sus4, add9, inversao
direcional esq/dir = tom | cima/baixo = volume | Select = onda | L3 = maior/menor
Fone com DAC USB: conecte antes de abrir o app; o Android usa o DAC sozinho.
Se o build der erro, copie a mensagem do log e mande para o Claude corrigir.
